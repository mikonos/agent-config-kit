# 06-timeline - 六爻源流时间线

调研日期：2026-05-07

## 结论

此 skill 的源流应写成“京房奠基纳甲，野鹤老人实占化，王洪绪系统纠偏”，而不是把六爻全部归功于一个人。

## 时间线

| 时间 | 节点 | 对 skill 的影响 |
|---|---|---|
| 西汉 | 京房易学与纳甲传统形成源头背景 | 提供干支、五行、卦爻关系的底层语言 |
| 唐宋以后 | 火珠林、纳甲、六亲、世应等体系持续流传 | 形成六爻占断的技术框架 |
| 明清之际 | 六爻典籍与断法高度繁杂 | 后来“增删”“正宗”的纠偏对象 |
| 1690 年 | 李文辉据野鹤老人手抄本及自身实践增删成《增删卜易》 | 本 skill 的实占主轴 |
| 康熙三十年前后 | 《增删卜易》早期版本流传 | 提供后世学习与整理基础 |
| 清代 | 王洪绪《卜筮正宗》辑撰 | 强化“阴阳、动静、生克制化”与反神煞滥用 |
| 现代 | 在线古籍、排盘工具、教学视频普及 | 使用门槛降低，但误断和过度神秘化风险上升 |

## 最新动态

无“人物动态”。2026 年可用的更新主要是古籍在线化、现代注解与排盘工具普及。
