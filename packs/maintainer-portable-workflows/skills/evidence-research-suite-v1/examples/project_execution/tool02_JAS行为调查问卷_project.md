# 工具2：JAS行为调查问卷 — product AI-Native 家庭日历机

> **方法论**：Jenkins Activity Survey (JAS) — 量化用户行为倾向  
> **产品**：product — AI-Native 家庭日历机 / 家庭 AI 中心  
> **评分标准**：李克特5分量表（1=非常不同意 → 5=非常同意）

---

## 量表说明

本问卷改编自 Jenkins Activity Survey，从三个行为维度量化家庭日程管理者的购买决策和使用行为倾向：

- **SI（Speed &amp; Impatience / 速度与急躁）**：时间紧迫感、行动节奏、对延迟/等待的容忍度
- **JI（Job Involvement / 工作投入）**：对家庭管理这件"工作"的心理投入程度、成就导向
- **HDC（Hard-Driving &amp; Competitiveness / 进取与竞争）**：对高标准的追求、与他人比较的倾向

---

## 评分方法与用户分群

### 评分计算
- 每个维度总分 = 该维度 7 题得分之和（范围 7-35）
- 维度均分 = 总分 / 7（范围 1.0-5.0）
- 综合分 = 三维度均分加权平均

### 分群标准

| 分群 | SI 均分 | JI 均分 | HDC 均分 | 用户画像 | 产品策略 |
|---|---|---|---|---|---|
| **极速掌控型** | ≥4.0 | ≥4.0 | ≥3.5 | 高要求、高投入、追求极致 | Premium硬件 + 全功能订阅，早期种子用户 |
| **认真管家型** | 3.0-4.0 | ≥4.0 | 3.0-3.5 | 投入高但不急躁，稳扎稳打 | 核心目标用户，重功能深度 |
| **效率务实型** | ≥4.0 | 3.0-4.0 | ≤3.0 | 追求速度但不追求完美 | 重视响应速度和易用性 |
| **从容享受型** | ≤3.0 | ≥3.5 | ≤3.0 | 认真但不急，享受过程 | 重视美感和仪式感设计 |
| **随遇而安型** | ≤3.0 | ≤3.0 | ≤3.0 | 低投入，不追求也不焦虑 | 非核心目标用户 |

### 与目标用户群的映射

| JAS分群 | 对应Tool4用户群 |
|---|---|
| 极速掌控型 | A. Mental Load妈妈（极致型） |
| 认真管家型 | A. Mental Load妈妈 + B. 调度员 |
| 效率务实型 | C. 时间优化效率者 |
| 从容享受型 | D. 结构空缺老人 |
| 随遇而安型 | F. 随遇而安独居者 |

## 分析价值

- **SI高分群体**：对Skylight"同步慢/设置复杂"的痛点最敏感 → 强调"即插即用、实时同步、语音秒建"
- **JI高分群体**：最可能为AI高级功能付费订阅 → 强调"让你的家庭管理达到new level"
- **HDC高分群体**：适合早期种子用户和口碑传播 → 强调"你朋友圈里第一个用上家庭AI中心的人"
