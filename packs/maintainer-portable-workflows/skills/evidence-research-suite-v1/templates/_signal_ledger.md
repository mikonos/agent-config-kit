## 1. 渠道与获客优先级

> 来源主要 Tool 4（圈层 / 扩张路径）、Tool 8（合作渠道）。填：谁先卖、谁后卖、各走什么渠道。提醒——区分"先卖给谁"（第一批客户）和"产品为谁而做"（定位靶心），别混。

## 2. 投放时机 / 营销触发点

> 来源主要 Tool 4（各群"什么时候真会买"）、Tool 7（触发事件）。填：每个群"什么事件发生时她才会真的去找产品"——这是投放时机和广告创意触发点。注意标出"多步购买"型的群（第一次受刺激不会搜产品、要被外部内容点醒后才搜）。

## 3. 正面卖点

> 来源主要 Tool 7（标 [大雇佣] / [Big Hire] 的功能）。填：落地页 hero 区、演示高调讲的卖点。一并记下营销主语言（哪些说法能用、哪些会触发用户抵触）。

## 4. 打消顾虑（焦虑阻断器 / 反-雇佣阻断器）

> 来源主要 Tool 7（标 [焦虑阻断器] / [反-雇佣阻断器] 的功能）。填：**不当卖点、当信任 / FAQ 讲**的内容。这类功能负责"不让已经动心的人退出去"，不负责"把人吸引进来"——营销讲法和正面卖点完全相反，要单独记。

## 5. 演示脚本 / 落地页结构

> 来源主要 Tool 7（演示流程）、Tool 3b（创新概念 / 英雄概念）。填：演示和落地页的内容顺序、哪些功能要捆绑演、哪些功能不能进演示视频。

## 6. 定位语言

> 来源主要 Tool 4（定位判断）、Tool 1（产品灵魂 / slogan）、Tool 8（定位改写）。填：营销主语言、品牌叙事内核、竞品对标话术（真正的对手往往不是同类产品，而是用户现在那套变通方案）。

## 7. 信任要素

> 来源主要 Tool 7（架构约束）、Tool 10（隐私 / 数据相关问卷结果）。填：营销信任话术背后的产品事实底气——隐私话术必须有架构事实撑着，否则是空话。
