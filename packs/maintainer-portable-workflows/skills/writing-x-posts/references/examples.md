# Examples (X / Twitter)

## Single post (insight)
Most “productivity” advice fails for one reason:

It optimizes for *feeling busy*, not *finishing work*.

If you want output, track:
1) one weekly deliverable
2) one daily constraint
3) one “stop doing” list

## Thread (problem → solution)
1/ You don’t need more ideas.
You need a system that turns ideas into published work.

2/ The trap: you collect.
Articles. Notes. Links.
But nothing ships.

3/ The fix is boring:
One pipeline, every time.

4/ Step 1 — Capture fast (no structure).
Write the raw thought in 30 seconds.

5/ Step 2 — Distill later (one sentence).
If you can’t explain it in one line, you don’t understand it yet.

6/ Step 3 — Publish small.
One idea per post. One post per day beats one “perfect” post per month.

7/ If you want, I can share the exact template I use.
Reply “template”.
