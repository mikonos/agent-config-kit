# QuantAnalysis 量化分析框架

> Phase 8 产出文件 `JTBD_QuantAnalysis_[品类].md` 的完整结构模板。
> 10 个分析维度，顺序不可调换（后面的维度依赖前面的结论）。

---

## 文件头部

```yaml
---
date: {YYYYMMDD}

epistemic_status: empirical

```

## 维度二：信号类型分布

```markdown
## 二、信号类型分布（Signal Type × 星级）

| 星级 | hire_moment | fire_moment | workaround | wishlist |
|------|-------------|-------------|------------|---------|
| 1★ (n=N) | ...% | ...% | ...% | ...% |
...

**核心洞察**：
1. fire_moment 峰值在哪个星级？（通常 2★ 最高，1★ 有更多 DOA）
2. workaround 和 wishlist 在哪个星级最集中？（通常 4★ 最高）
3. 5★ 中 workaround 比例说明什么？
```

**统计方法**：按星级分组，统计 `signal_type` 字段各值出现次数 / 该星级总行数

## 维度三：四力分布热力图

```markdown
## 三、四力分布热力图（×星级）

| 星级 | Push | Pull | Anxiety | Habit |
|------|------|------|---------|-------|
| 1★ | N(%) | N(%) | N(%) | N(%) |
...

**核心洞察**：
1. Anxiety 峰值星级（通常 3★）说明什么？
2. 哪个星级的四力最复杂（四力同时出现）？
3. 高星的 Pull 模式 vs 低星的 Push/Anxiety 模式对比
```

**统计方法**：按星级统计各 `force_*` 字段非空行数 / 该星级总行数

**数据质量注记**：如发现某字段 100% 非空，需注明「可能是模板副作用，方向性结论有效但绝对数不可靠」

## 维度九：Job × Feature 交叉矩阵

```markdown
## 九、Job × Feature 交叉矩阵

（数字 = 相关 Feature 被提及次数；√ = 已实现满意；✗ = 已实现不满意；○ = 未实现）

| | F01 | F02 | F03 | ... |
|---|---|---|---|---|
| **J01** | √N ✗N | ... |
| **J02** | ... |

**矩阵关键发现**：
1. 横跨所有 Feature 的「超级 Job」是什么？
2. 单点依赖某个 Feature 的 Job 是什么（单点故障风险）？
3. Job 的核心 Feature 失败率最高的组合是什么？
```

**构建方法**：从 FeatureList 的「关联 Job」列反向构建。每个 feature 对应的 Job，用 feature 的 satisfied/frustrated/requested 频次填入矩阵。

## 数据质量附录（必须包含）

```markdown
## 附录 A · 数据质量说明

| 字段 | 问题 | 影响范围 | 建议 |
|------|------|---------|------|
```

常见需要记录的质量问题：
- 四力某字段 100% 非空（模板副作用）
- anxiety_theme 字段含 signal_type 值（误填）
- raw_job 被归纳压缩导致唯一数偏低
- signal_type 字段含非标准值（文本误填）
