# Glenford Myers

## 核心来源

- `The Art of Software Testing`
- Wiley / O'Reilly 书籍介绍与长期版本信息

## 对测试用例设计最关键的贡献

### 1. 把测试目标从“证明程序正确”改成“更高概率发现错误”

- Myers 最经典的贡献，是重新定义测试的心理模型。
- 这会直接改变用例设计方式：
  - 不再为证明 happy path 正确而写用例
  - 而是主动寻找更可能击穿程序的输入与条件

### 2. 经典黑盒用例设计方法的普及者

- 等价类划分
- 边界值分析
- 错误猜测
- 这些方法不是他一人发明，但他把它们整理成了测试设计的基础语法。

### 3. 用例设计是一种纪律化思维

- Myers 的风格偏简洁、可教学、可普及。
- 他适合做“底层训练”：让团队先建立最基本的测试设计框架和反直觉意识。

## 对综合 skill 的启示

- Myers 这条线负责：`经典方法底座`
- 他提供的是最稳的基础层：让测试用例设计不至于只剩经验和直觉
