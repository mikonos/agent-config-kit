# Boris Beizer

## 核心来源

- `Software Testing Techniques`
- `Black-Box Testing`
- Google Books / Open Library 书籍说明

## 对测试用例设计最关键的贡献

### 1. 用系统化覆盖视角看测试设计

- Beizer 的长处是结构化、系统化、技术化。
- 他把测试用例设计从经验问题提升为覆盖问题、模型问题、结构问题。

### 2. 强调 testability 与设计本身相关

- 书籍说明明确强调：`design for testability is as important as testing itself`
- 这意味着好用例不是事后补救，而与系统是否可观察、可控制、可分解高度相关。

### 3. 适合复杂逻辑、规则密集、状态转换多的系统

- 在规则引擎、接口矩阵、复杂业务流程、状态机式系统里，Beizer 的思想尤其重要。
- 他帮助测试者从“点状 case”上升到“结构性覆盖”。

## 对综合 skill 的启示

- Beizer 这条线负责：`结构覆盖`、`模型化设计`、`可测性`
- 他让这个主题 skill 不会沦为只讲经验、不讲系统性
