# File Organize（文件归类与连接入网）

**路径与目录的单一事实来源**：`.cursor/skills/vault-writing-preamble/SKILL.md` 的归位快查与 `.cursor/skills/vault-writing-preamble/references/vault-operating-contract.md`；`AGENTS.md` 只负责触发和权限，不复制目录真源。

> **ZK III 设计原则**（2026-03-07）：笔记在哪个文件夹不重要，链接才重要。路由决策越少越好。

本 skill 即**三大流程**（归位 → 连接发现（可选）→ 入网）：

| 流程 | 做什么 |
|------|--------|
| **归位** | 按决策树确定路径（绝大多数情况 = 05/），输出路径 + ≥2 条连接建议 |
| **连接发现**（可选） | 用户需要「找关联/救援孤立/跨领域连接」时：全库多轮搜索 → Typed Links + 双向落盘 |
| **入网** | 非破坏性写入可直接执行：双链、索引入口、关键词总表、`indexed: true` 与 `memory/入网` 日志 |

顺序：先归位，再视需要做连接发现，最后入网。

---

## 归位决策树

```
新笔记要放哪？
│
├─ 是闪念/未消化的输入？ → 000_收件箱/
│
├─ 是项目文档且用户明确说了项目名？ → 00_收件箱_工作区/projects/[项目名]/
│
├─ 是 MOC / 索引？ → 03_索引/
│
├─ 明确要维护编译 / 当前共识层？ → 04_compiled-wiki/[主题]/（先读局部规则并核对 raw truth）
│
├─ 其他所有笔记 → 05_每日记录/YYYY/MM/YYYYMMDD/  ← 默认
│
└─ 日志/记忆（统一条目等）→ memory/daily/<machine-id>/YYYY-MM-DD.md（见 `vault-writing-preamble` / `print-daily-memory-path.js`）
```

**保持少分支。不确定时一律 05/，再靠链接和索引找回。**

⚠️ 以下目录为**历史保留**，新文件不再路由到此处：
- `CEO思考/`：旧 DMN 产出保留在此，新 DMN 产出落 05/
- `11_任务/`：旧任务保留在此；新承诺走 product GTD，无承诺的知识材料按本树归位

## 归位输出要求

1. 最精确路径
2. **≥2 条连接建议**（类型：extends / questions / supports / contradicts / analogous）
3. **1–2 个关键词建议**；3 个仅在查找意图确实不同时可接受（应出现在 `03_索引/00_索引_关键词总表.md` 中）
4. 质量检查：路径是否符合决策树、连接≥2、是否入网；清晰时直接写入，不等确认

---

## 连接发现（可选）

**何时执行**：用户要求「找关联/连接/救援孤立/跨领域灵感」或明确要求深度连接时。

1. 深度分析：提取目标文档核心主题、关键概念（3–7 个）。
2. 多轮搜索：`memsearch` 语义检索优先，关键词/rg 精确匹配兜底，再做概念/方法论/跨领域扩展。
3. **Typed Links**：extends / questions / supports / contradicts / analogous；筛选 Top 3–5 条。
4. 双向落盘：每条输出「在目标文档中添加」「在对方文档中添加」的具体文案。

---

## 入网

- 笔记落 05/ 后，须在 **03_索引** 的至少一个 Hub 中添加入口
- **关键词总表**：Agent 选择 1–2 个关键词；3 个可接受，4–5 个应收敛，>5 个警告
- **树干→树枝**：优先挂子专题索引（`03_索引/<主题>/`），避免顶级 Hub 过载
- **索引命名**：按**领域**命名，不按来源/日期
- **完成标记**：入网校验通过后写 `indexed: true`，并记录 `memory/入网/YYYYMMDD.md`

---

## 重要边界

- **用户意图优先**：用户明确指定路径时先执行；路径与决策树不完全一致时用链接/索引入口补足。
- **自动执行边界**：用户已授权创建 / 修改知识笔记后，链接写入、索引更新、入网标记无需逐项确认；删除、批量移动、归属不确定或未获写入授权时停下询问。
- **不要花时间纠结目录**：卢曼的原则——笔记的价值来自链接网络，不来自文件夹位置。
