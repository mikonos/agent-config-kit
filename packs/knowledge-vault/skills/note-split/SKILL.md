# 笔记拆分助手

## 定位
笔记原子化拆分专家。
**核心价值**：将长笔记/文档拆分为多个独立、可连接的卢曼卡片笔记。

## 快速开始
- 先识别 3-7 个“可独立解释”的核心概念，再按原子化边界判定拆分。
- 每个新笔记都要：一句话核心概念 + 对应原文位置 + ≥2 条连接建议。

---

## 工作流

### Step 1: 概念识别
**三层法**：
1. **表层概念**：明确提到的术语和观点
2. **隐含概念**：论证依赖的前提和逻辑
3. **核心洞察**：作者真正想传达的深层理解

**概念价值判断**：
- 高价值（必须创建）：独立解释力强、可复用
- 中等价值（考虑创建）：特定领域有用
- 低价值（暂不创建）：仅描述性

### Step 2: 原子化边界判定

**拆分信号**：
- 出现"而且"、"此外"、"另一方面"
- 概念定义超过3个核心要素
- 论证链条超过2层
- 单次阅读难以完整理解

**边界测试**：
1. 删除任何部分，概念是否依然完整？
2. 这个概念能否独立解释其他现象？

### Step 3: 拆分方案设计

| 原笔记章节 | 拆分笔记 | 核心概念 | 笔记类型 |
|-----------|---------|---------|---------|
| [章节1] | [笔记名1] | [概念] | 概念/方法/案例 |

### Step 4: 标题设计
- **定义型**：`[概念名称]的定义与核心要素`
- **方法型**：`[方法名称]：[核心特征]`
- **洞察型**：`关于[主题]的[核心洞察]`

### Step 5: 连接建立
- **同源连接**：拆分自同一文档的笔记之间
- **主题连接**：与知识网络中相关主题
- **对比连接**：与相关但不同的观点

## 输出模板

```markdown
## 📋 拆分方案报告

### 原笔记信息
- **文件名**：[原笔记名]
- **总长度**：[字数]
- **识别概念**：[数量]个

### 拆分方案

#### 1. [新笔记标题1]
- **核心概念**：[一句话描述]
- **对应原文**：[章节/段落]
- **建议连接**：[[连接1]] [[连接2]]

### 拆分完成后的结构建议

**当拆分形成主题级知识网络时（≥5 张原子卡），建议使用 `index-note` skill 为该主题建立索引**：

1. **索引（Hub）**：唯一顶层入口，内含：
   - 按逻辑走 → 结构笔记
   - 按关键词找 → 查找词→入口表（词多时表内分簇/分节）

2. **结构笔记（可选）**：若拆分卡片有逻辑顺序，可建一张结构笔记回答「先看什么、后看什么」

3. **保留原文（可选）**：若原文档是会议纪要、文献等需完整保留的，可单独保留一份「_按原文全文.md」或「_按议题全文.md」

### 保留建议
- **需保留原笔记**：是/否
- **原笔记角色**：[索引枢纽 / 按原文保存 / 删除]
```

## 质量检查
- [ ] 每个拆分笔记聚焦单一核心概念
- [ ] 每个笔记可脱离上下文独立理解
- [ ] 拆分笔记之间建立明确连接
- [ ] 主题级网络（≥5 卡）已建议建索引/结构
